# Customer Data Quality Project

## Overview

This project demonstrates a simple customer data quality process.

The project identifies customers with missing IDs and duplicate customer IDs and creates a cleaned customer dataset.

## Data Quality Checks

- Identify customers with missing customer IDs
- Identify duplicate customer IDs
- Remove records with missing IDs
- Remove duplicate customer records
- Generate a cleaned customer dataset

## Project Structure

- `data/customers.csv` - Sample customer input data
- `src/clean_customers.py` - Python data quality processing
- `output/cleaned_customers.csv` - Cleaned customer data
